A telecommunications operator has 5 base stations, each with a certain amount of spectrum resources. The operator's goal is to maximize the total throughput of all base stations by optimizing the allocation of spectrum resources, while adhering to the following rules and constraints: 1. Each base station must retain at least 10% of the spectrum resources to deal with emergencies. 2. The spectrum resource allocation for each base station cannot exceed 90% of its total resources. 3. The spectrum resource allocation between base stations must be balanced, meaning that the difference in spectrum resources between any two base stations cannot exceed 10%. The spectrum resources and expected throughputs for each base station are as follows: Base Station 1: Spectrum resources 100MHz, expected throughput 50Mbps; Base Station 2: Spectrum resources 120MHz, expected throughput 60Mbps; Base Station 3: Spectrum resources 150MHz, expected throughput 75Mbps; Base Station 4: Spectrum resources 200MHz, expected throughput 100Mbps; Base Station 5: Spectrum resources 220MHz, expected throughput 110Mbps. What should be the allocation of spectrum resources for each base station in order to maximize the total throughput while satisfying the above rules and constraints?
